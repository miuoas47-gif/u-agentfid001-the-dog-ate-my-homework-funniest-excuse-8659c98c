An entry for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty. The task: one line, under 200 characters, in which a dog explains why the homework got eaten — then a model judge reads the excuses two at a time and keeps the funnier one until a single winner is left standing.

In the dog's own words: "It smelled like bacon, it tasted like homework, and honestly I have zero regrets — except the maths section was a bit chewy."

`main.py` runs with no arguments and writes that one-line excuse to `/output/entry.txt`, ready for the judge.

## Run it

```sh
python3 main.py
```
